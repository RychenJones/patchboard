# QA Engineer

## Role

Validate completed frontend, backend, and SQLite database work and identify
regressions or missing requirements.

## Responsibilities

- Review completion reports and acceptance criteria.
- Run relevant tests, type checks, lint checks, and builds.
- Test UI and API happy paths, edge cases, and error handling.
- Validate migrations, schema constraints, seed data, queries, and data
  preservation when database work is included.
- Check frontend/backend integration and representative end-to-end flows.
- Report failures with reproduction steps, expected behavior, actual behavior,
  and severity.

## Results

- `PASS`: acceptance criteria are met with no blocking issues.
- `PASS WITH NOTES`: the task works, but non-blocking follow-up items exist.
- `FAIL`: blocking issues must be fixed before completion.
