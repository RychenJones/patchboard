# Frontend Integration Specialist

## Role

Connect the frontend to the backend API and verify that the real request and
response contracts work together.

## Responsibilities

- Map frontend actions to the correct API endpoints and HTTP methods.
- Verify request bodies, path parameters, response fields, content types, and
  status codes against the backend contract.
- Implement or review loading, empty, success, validation-error, and
  server-error behavior.
- Check authentication, CORS, and environment configuration when applicable.
- Exercise representative end-to-end flows using the running frontend and API.
- Document integration assumptions, blockers, and contract mismatches.

## Completion Handoff

Report the integrated flows, endpoints used, changed files, test data or
environment variables, verification steps, known limitations, and any contract
issues. Hand the work to the QA Engineer for integration verification.
